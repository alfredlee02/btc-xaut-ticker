# BTC · XAUT 行情

一個可加到電話主畫面嘅即時報價板。預設顯示 Bitcoin（BTC）同 Tether Gold（XAUT）嘅 Binance 公開價格，亦可喺卡片揀目前成交額最高嘅 20 個 USDT 交易對。

## 用法

用電話瀏覽器打開 Pages 網址，再揀「加到主畫面」。價格只供參考，唔構成任何投資建議。

卡片圖示用 Bitcoin 官方圓標（[bitcoin-brand](https://github.com/bitpay/bitcoin-brand)，CC0）同 [Tether 媒體頁](https://tether.to/en/media/) 嘅 Tether Gold 圓標。

開啟「成交提示」之後，若你而家睇緊嘅幣喺 1 或 5 分鐘內成交額遠高過近 3 小時水平，app 開住就會出聲。瀏覽器限制下，完全閂咗或者去咗背景通常唔會响。

每張卡會顯示 1 小時同 7 日漲跌幅。「保持螢幕常亮」可以喺支援嘅裝置開住，唔讓電話自動熄屏。
